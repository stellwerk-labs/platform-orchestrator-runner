# Runner v3.3.0

Optional monthly cost estimation uses the pinned classic Infracost `v0.10.49` executable, packaged as `v0.10.49+stellwerk.1` with a documented dependency security/compatibility patch, and customer-owned Cloud Pricing API credentials.
The installation Admin controls enablement; the default is disabled.
Manual and Drift plans share advisory aggregate cost logging, with explicit partial/unknown coverage and possible upstream defaults.
Failure never blocks the plan or observation.

The image source-builds Infracost using Go `1.26.11`, scans the actual executable and ships its production dependency legal notices and SPDX inventory under `/licenses/infracost/`.
No plugins or software downloads occur during estimation.

See [cost estimation](../cost-estimation.md) for privacy, credential transport, coverage and pricing limits.
