# Runner v3.2.0

Runner 3.2.0 adds optional `environment-observation/v1` execution. A marked
`plan_only` job runs a full refreshed Terraform/OpenTofu plan and returns a bounded
summary of observed changes and proposed actions. It does not apply the plan or
write refreshed state. Resource addresses, attribute/output values and provider
diagnostics are excluded. Invalid protocol/mode combinations fail before execution.

Deploy with the reviewed compatible CP 3.3.0, DP 4.2.0 and IAM 2.6.0 image set,
pinned to the release manifest's actual digests. The matching public SDK contracts
are CP/DP `shared/v3` v3.1.0 and IAM `shared` v1.3.0. Orchestrator provides authorization,
baseline selection, queue admission and persistent per-Runner capacity. Runner
does not add an independent local semaphore. Enable the protocol only with those
matching Orchestrator controls; absent structured results from older Runners are
unavailable observations, not evidence of a clean environment.

The bundled engine advances from OpenTofu 1.10.0 to unchanged official 1.13.2
executables. The release owner explicitly accepts their 11 known symbol advisories
FOR THIS RELEASE after rechecking official artifacts. This does not remediate
them or claim they are unreachable. [The version-scoped disposition](vendor-residuals-v3.2.0.md)
records exact per-architecture executable hashes, advisory IDs and complete
finding inventory. Source and the Runner executable still require strict scans.
New/changed vendor findings, unknown tool errors, wrong hashes and release
families other than 3.2.0 and its candidates fail closed.

Retain normal backend locking, provider credentials, state encryption keys and
artifact/history access during upgrades and recovery. Use the required real
legacy-history and observation integration gates for the intended image set.
Provider/backend compatibility and states written by a newer engine need their
own qualification; this release does not authorize a blanket engine downgrade.

This Runner tag publishes the generic image. Agent charts and private plugin
source, packages and licences remain separate release surfaces.

The image preserves Runner's EUPL license, Go LICENSE/PATENTS, the complete
production dependency notice closure and exact EUPL module provenance. It also
ships the unchanged official OpenTofu LICENSE, README and changelog plus an
immutable source reference. A complete hash manifest and final nonroot copy
validation fail the build if notices are missing or changed. This preserves
notices; it does not change the accepted vendor vulnerabilities or add an image
signature. The normal hosted AMD64 final-image gate and both-architecture notice
contracts remain required before the protected publisher.
