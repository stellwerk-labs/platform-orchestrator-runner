# Runner v3.2.0-rc.2

This candidate adds the optional `environment-observation/v1` protocol for full,
refreshed Terraform/OpenTofu plans. Marked `plan_only` jobs return a bounded
structured summary without applying the plan or writing refreshed state. Resource
addresses, attribute/output values and provider diagnostics stay out of that
summary. Unsupported markers and mode combinations fail before execution.

Use the coordinated CP 3.3.0, DP 4.2.0 and IAM 2.6.0 release train, with the
matching candidate image digests recorded in the release manifest. Its public
SDK contracts are CP/DP `shared/v3` v3.1.0 and IAM `shared` v1.3.0. Orchestrator owns
authorization, queue admission and persistent Runner capacity; declaring the
protocol on a Runner alone does not provide those controls. Older Runners can
return no structured observation, which Orchestrator must treat as unavailable.

The image uses the unchanged official OpenTofu 1.13.2 executables. The release
owner explicitly accepts their 11 known symbol advisories for Runner 3.2.0 and
its candidates only, after rechecking official artifacts. This is not a security
fix or an unreachability claim. See the exact hashes, IDs and fail-closed policy
in [the release-scoped vendor disposition](vendor-residuals-v3.2.0.md).
Source and the Runner executable retain strict vulnerability checks. Changed
vendor bytes/findings, scanner errors and other release families remain denied.

Keep normal backend locking, credentials and state/history access. Qualify the
1.10.0 to 1.13.2 engine transition against the intended providers and state
backends; do not infer universal downgrade compatibility. The existing legacy
history and observation artifact gates remain required. This candidate's
qualification does not certify a later stable image or an arbitrary cloud backend.

This tag publishes the generic Runner image. Agent charts and private plugins
have separate release identities and are not published by this tag.

The image preserves Runner's EUPL license, Go LICENSE/PATENTS, the complete
production dependency notice closure and exact EUPL module provenance. It also
ships the unchanged official OpenTofu LICENSE, README and changelog plus an
immutable source reference. A complete hash manifest and final nonroot copy
validation fail the build if notices are missing or changed. This preserves
notices; it does not change the accepted vendor vulnerabilities or add an image
signature. The normal hosted AMD64 final-image gate and both-architecture notice
contracts remain required before the protected publisher.
