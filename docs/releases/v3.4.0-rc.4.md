# Runner 3.4.0-rc.4

Native pipeline workers execute signed, UUID-bound commands using a shared PostgreSQL journal and stable worker slots. Gateway delivery and replay retain command, saved-Plan and result identity. A saved Plan is consumed once, and an uncertain Apply stays held for reconciliation rather than being retried as a new infrastructure operation.

Pipelines support direct Apply, explicit Plan and reviewed Plan/Apply flows with approved steps before Plan, at Plan checks and after Apply. Steps must match the installed approved catalogue and declared retry contract. Reviewed cost-based approval requires valid, complete comparison evidence; unavailable or unknown evidence does not auto-approve. If a post-Apply task fails, the infrastructure can remain applied while the pipeline is unsettled.

Authenticated readiness, status and drain controls support replacing a stable worker slot. Graceful parent termination closes new-stage admission and waits for admitted work. Forced termination, lost database authority and ambiguous external effects remain recovery conditions, not evidence that execution was absent.

Native operation requires an external session-affine PostgreSQL primary with durable writes and a mandatory synchronous standby, separate initialization and runtime roles, retained encryption identity, provisioned trust, an approved tool catalogue, a supported state backend and external activation authority. Transaction-mode pooling is unsupported. State remains in its configured backend.

Native format 7 refuses older Native journals without rewriting them; there is no automatic history migration or key replacement. Preserve old history and unresolved effects during reconciliation. The chart retains its remote Job default, and Native activation is explicit. See the Native packaging, PostgreSQL storage and restore documentation before installation.

Native diode reverse imports bind each site to its organization, server-issued Runner UUID and configured verification key. Before upgrading an existing Native diode exporter, follow the [consumer cutover procedure](../native-diode-ingress.md#existing-native-exporter-cutover) to preserve queued commands.
